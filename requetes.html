Guerre mondiale - Eric

En liens avec la seconde guerre mondial, KDou souhaiterait connaitre les fournisseurs qui viens d’Allemagne et de France.

SELECT Fournisseur.Societe FROM Pays INNER JOIN Fournisseur ON Pays.NoPays = Fournisseur.NoPays WHERE (((Pays.NoPays) = 1)) OR (((Pays.NoPays) = 9));

Partenariat - Patrick

L'entreprise souhaiterait connaître les 5 entreprise qui ont contribuées le plus au chiffre d'affaire

SELECT TOP 5 C.CodeCli, C.Societe, SUM(DC.Quantite * Produit.CoutAchat * CA.CoefMarge * (1 - DC.Remise / 100)) AS ChiffreAffaires FROM ( ( ( Clientele C INNER JOIN Commande ON C.CodeCli = Commande.CodeCli ) INNER JOIN DetailCommande DC ON Commande.NoCommande = DC.NoCommande ) INNER JOIN Produit P ON DC.RefProd = P.RefProd ) INNER JOIN Categorie CA ON P.CodeCateg = CA.CodeCateg GROUP BY C.CodeCli, C.Societe ORDER BY ChiffreAffaires DESC;

C'est alors que je me suis dit qu'on pourrait voir quels produis sont les mieux vendus par catégorie pour en acheter des quantités plus importantes pour d'une part évité de recommander des produis et donc de consommé d'avantage et d'une autre par économisé de l'argent car on pourra négocier des prix plus avantageux avec les nouvelles quantités demandées. Elle se décompose en 2 requête, la 1ere affiche le nombre de vente d'un produis avec

SELECT C.CodeCateg, C.NomCateg, P.RefProd, P.NomProd, SUM(D.Quantité) AS TotalVendu FROM ( DetailCommande AS D INNER JOIN Produit AS P ON D.[Réf produit] = P.RefProd ) INNER JOIN Categorie AS C ON C.CodeCateg = P.CodeCateg GROUP BY C.CodeCateg, C.NomCateg, P.RefProd, P.NomProd; SELECT Q1.NomCateg, Q1.NomProd, Q1.TotalVendu FROM Q_TotalVentes AS Q1 WHERE ( ( (Q1.TotalVendu) = ( SELECT MAX(Q2.TotalVendu) FROM Q_TotalVentes AS Q2 WHERE Q2.CodeCateg = Q1.CodeCateg ) ) );
